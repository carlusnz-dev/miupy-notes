# Estilo

`tokens.json` é a base visual provisória para o frontend; `referencias.json` registra fontes externas e a interpretação aplicada ao produto. As fontes Inter e Instrument Serif estão em WOFF2 local em `apps/web/src/assets/fonts/`, com licenças OFL ao lado. O tema usa preto, branco e cinzas; o mesh é uma camada discreta. Ainda falta validar visualmente em navegador com o MCP. Ao desenhar telas, verifique contraste, teclado, larguras diferentes e movimento reduzido.
