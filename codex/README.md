# Codex neste projeto

Codex lê `AGENTS.md` na raiz. As rotinas de design e revisão estão em `skills/`. Os arquivos aqui são modelos para a camada `.codex/`, indisponível para escrita neste ambiente; **não são carregados automaticamente**.

Quando `.codex/` estiver gravável, copie `config.toml.example` para `.codex/config.toml` e os arquivos de `agents/` para `.codex/agents/`. Revise a configuração efetiva com `/debug-config`. Não copie credenciais para esses arquivos.
