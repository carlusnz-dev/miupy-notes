## Decisões

- O proprietário vem da identidade autenticada no backend. O template de notas não monta endpoints pessoais enquanto esse mecanismo não existir.
- A fronteira pública entre módulos é `index.ts`; `module.ts` faz a composição interna.
- GSAP foi declarado para interações futuras; a animação base do mesh usa CSS e respeita `prefers-reduced-motion`.
